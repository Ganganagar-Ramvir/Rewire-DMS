Ek baar screen dikh gayi, wahan role kya-kya kaam kar sakta hai (edit/submit/approve) — wo yahan se control nahi hota, wo fixed hai (role ke hisab se app/database ke andar already decide kiya hua). Isliye do roles ka ek hi screen par tick dikh sakta hai lekin ek "kaam" kar paye aur dusra sirf "dekh" paye — ye normal hai, koi bug nahi. Screen / Tab
Values added/removed here update the matching dropdown across the app immediately — no code change needed.
Works on any table, any columns. First column in your file is the match key (must be unique per row — usually id, or lead_no for leads). Every other column present in the file gets updated for the matching row; columns you leave out of the file are untouched. Always Preview before running — this writes directly to the database and can't be undone in bulk.
